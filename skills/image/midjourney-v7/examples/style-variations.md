## Using Style References (`--sref`)

### With URL
```
Portrait in specific artistic style --sref [URL-of-style-example] --sw 300 --ar 3:4
```

### With sref Code
```
Landscape scene --sref 1234567890 --sw 400 --ar 16:9
```

### Style Weight (`--sw`) Guide
- `--sw 100`: Subtle style influence
- `--sw 300`: Moderate style application
- `--sw 500`: Strong style adherence
- `--sw 1000`: Maximum style dominance

## Quick Style Reference

**For Realism:** Low `--s` (50-150) + photography terms  
**For Artistic:** High `--s` (400-600) + painting/art terms  
**For Stylized:** Medium-High `--s` (300-500) + specific genre  
**For Abstract:** Very High `--s` (600-1000) + abstract terms  

**Use `--sref` + `--sw`:** When you need exact style matching  
**Use `--s` alone:** When you want Midjourney's interpretation  

---

**Pro Tip:** Browse srefcodes.com for V7 style reference codes. Use `--sv 4` with old V6 codes, or default `--sv 6` for V7 native styles.
