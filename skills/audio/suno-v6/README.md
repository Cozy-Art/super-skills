## Research verification


Corrections / additions to research:
- Voices: research presents Voices as the strong v6 singer anchor → Voices FAQ still instructs selecting v5.5 ("other models don't support New Voices") while v5.5 is retired; v6 compatibility marked unverified — help.suno.com/en/articles/11362433
- Voices also unavailable to users under 18 and in some regions; Personas button replaced by Voices, Style Personas live inside Voices — same source
- Audio Influence slider appears only when an audio upload is used (research implied a general slider) — help.suno.com/en/articles/6141377
- Character limits: research gave only ~1,000 Style; live composer counters show Style 1,000 and Lyrics 5,000 (third-party observation, marked unverified as fixed spec) — hookgenius.app/learn/suno-v6-guide/
- Style Influence default reported as 50% (third-party; marked unverified; research said none found) — same source
- Exclude terms are displayed back with minus prefixes after style text; Vocal Gender and Personalize/My Taste exist in More Options (behaviour undocumented) — same source
- 8-minute duration is from "How long will my song be?", not the v6 FAQ (FAQ doesn't state it) — help.suno.com/en/articles/13924929
- Custom Models: added private/non-shareable, ~2–5 min training, must own rights — help.suno.com/en/articles/11362497
- Industry partners named WMG, BMG, Believe (not in skill; informational) — suno.com/blog/introducing-v6
- No official public Suno API documented; skill notes third-party wrappers aren't Suno syntax

Verified as stated in research: model lineup + plan access; pre-v6 retirement; 10 credits / 2 songs; Max Mode use cases; Variety 0 = full tag control; stems pricing (Auto 50, Split from Mix 10/stem, Advanced 10/stem Premier, up to 12 / ~100); downloads by plan; uploads 60 s free / 8 min Pro-Premier (older article lists 6–60 s / 120 s); Replace Section Pro/Premier, 2 options; Remaster Subtle/Normal(default)/High; Custom Models ≥6 songs, max 3, auto-upgraded to v6; Exclude location.

Unverified: Variety max/default; Style/Lyrics char limits as fixed spec; Style Influence default; v6 Voices compatibility; Vocal Gender options; Studio 2.0 32-bit/48 kHz multitrack export; Remaster plan/cost; Replace Section cost/length limits.
